# article-review

给一篇文章打分：按渠道（小红书 / 微信公众号）走九项维度，满分 100，输出总分、每项评语和最优先的三条修改建议。

只评文章本身的质量，不套用任何公司内部的内容标准。

## 用法

在 Claude Code 里把文章和渠道交给它：

```
/article-review
渠道：公众号
[粘贴文章全文]
```

渠道不写会先问，确认后再打分。

## 打分维度

**小红书（100 分）**：标题 10、开头钩子 10、内容价值 10、结构与节奏 15、逻辑完整 20、语言表达 10、可信度 10、平台适配 10、专业性 5

**公众号（100 分）**：标题 10、开头钩子 10、内容深度 10、结构清晰 15、逻辑完整 20、语言表达 10、可信度 10、结尾与行动召唤 10、专业性 5

## 几条打分纪律

- 严格打分，宁可低不要高：普通合格的文章落在 60–70 分。
- 每条评语必须引用原文，不写"整体不错"这类空话。
- 适度夸张、标题党倾向是加分项，只要正文撑得住。
- 没有可验证的细节不是缺点，只是拿不到加分。
- 结构对不上、深度停在描述，罚得重。
